# 核实记录

这里说明本书的依据是怎么核对的，以及哪些法律在编写期间发生了修订。每一章引用的全部来源，按章节汇总在 [依据清单](依据清单.md)，由脚本从正文自动生成。

## 核对方法

1. **法律法规**：条文号和内容，以全国人大网、中国政府网、最高人民法院、最高人民检察院、国家部委官网公布的文本为准，逐条打开原文核对，不凭记忆写条号。
2. **司法解释和规范性文件**：同样以「两高」和发文部委官网的原文为准；新旧规定冲突的，写明以新规定为准。
3. **学术研究**：只引用能确认真实存在的著作和论文，写明作者、年份、题目和出处；拿不准的，不引，降为 C 级的经验共识。
4. **经验类条目**：统一标为 C 级，写「经验共识，本书整理」，并在备注里写明例外和地区差异。
5. **原创**：正文全部为本项目原创撰写。选题参考过公开的人情世故讨论和开源项目，但不使用其文字；限制改编的项目只作为选题参考。

## 仍需读者自行核实的部分

- **地方规定**：养犬管理、燃放烟花爆竹、装修施工时间、产假和生育奖励假、婚俗改革等，各地规定不同，以当地最新规定为准。
- **数额标准**：小额诉讼的标的额上限、经济补偿的封顶基数等，与当地上年度工资水平挂钩，每年会变。
- **习俗**：第 27 章涉及的地方习俗，只写普遍的做法和「拿不准就问」的原则，具体以当地为准。
- **法律在变**：本书写作时以 2026 年 10 月能查到的文本为准。涉及打官司、签合同、维权等重要事项，请以最新法律文本和专业律师的意见为准。
