**讲清规则，也讲清人心。**

**知世故而不世故**：这里讲面子、人情、关系怎么运转，也把行贿、操控、PUA、杀猪盘这类灰色和黑色的套路摊开讲——讲它们，是为了让你认得出、躲得开、维得了权，不是教你用。

**不用全做**：这是一份备选单，不是任务清单。挑走一两条就算数，剩下的需要时再回来查。在线检索页可以按场景章节、换回什么、依据等级、花不花钱、要不要拉下脸筛选。

人情世故南北不同、城乡不同、家家不同。涉及法律、钱和人身安全的事，以法律条文、当地部门和律师的说法为准。发现写错了，欢迎[提 issue](https://github.com/changxueyi/renqing-shigu/issues)。

## 术语表

| 术语 | 解释 |
| --- | --- |
| 差序格局 | 费孝通提出的概念：以自己为中心，按亲疏远近一圈圈往外推的人际关系结构。 |
| 人情账 | 人与人之间帮忙、送礼、随份子形成的往来记录，讲究有来有往、大体对等。 |
| 弱关系 | 社会学家格兰诺维特的说法：联系不那么紧密的熟人，常常带来新的信息和机会。 |
| 互惠 | 别人先给了你好处，你会觉得应该回报的心理倾向；常被推销和骗局利用。 |
| 锚定 | 谈判或判断中，最先出现的数字会强烈影响后面的判断。 |
| BATNA | 谈判协议的最佳替代方案：谈不成时你还有的最好选择，它决定你的底气。 |
| 道德绑架 | 把一个可以商量的请求，包装成「不答应就是坏人」的道德考题。 |
| PUA | 网络用语，常指在恋爱、职场中通过吹捧、打压、孤立等手段对他人进行精神控制。 |
| 煤气灯效应 | 操控者反复否认对方的记忆和感受，让对方怀疑自己的判断。 |
| 情感勒索 | 利用恐惧、义务感和愧疚感，逼对方按自己的意愿行事。 |
| 强制控制 | 通过孤立、贬低、监控、限制等方式，长期控制伴侣或家人的行为模式。 |
| 杀猪盘 | 先以恋爱、交友建立信任，再诱导对方在虚假平台投资或博彩的诈骗。 |
| 帮助信息网络犯罪活动罪 | 简称「帮信罪」：明知他人利用网络犯罪，仍提供技术支持、支付结算等帮助。 |
| 安全账户 | 冒充公检法的诈骗话术，真实的公检法机关不存在要求群众转账的「安全账户」。 |
| 传销 | 以交纳入门费、发展下线人数或层级计酬为特征的违法经营模式。 |
| 非法集资 | 未经金融管理部门许可，以许诺回报的方式向不特定对象吸收资金。 |
| 商业贿赂 | 经营者为谋取交易机会或竞争优势，给予交易相对方工作人员等财物或其他好处。 |
| 斡旋受贿 | 国家工作人员利用本人职权或地位形成的便利，通过其他国家工作人员为请托人谋利并收受财物。 |
| 利用影响力受贿罪 | 国家工作人员的近亲属或关系密切的人，利用其影响为请托人谋取不正当利益并收受财物。 |
| 介绍贿赂 | 在请托人和国家工作人员之间沟通关系、撮合条件，使贿赂得以实现。 |
| 特定关系人 | 与国家工作人员有近亲属、情妇（夫）以及其他共同利益关系的人。 |
| 中央八项规定 | 2012 年中央政治局制定的改进工作作风、密切联系群众的规定，是公职人员行为的重要约束。 |
| 经济补偿 | 劳动合同解除或终止时，单位按工作年限支付给劳动者的补偿，俗称「N」。 |
| 竞业限制 | 掌握商业秘密的员工离职后一定期限内不得到竞争对手处工作，最长两年，单位须按月补偿。 |
| 服务期 | 单位出资为劳动者提供专项技术培训后约定的服务年限，提前离职可能要支付违约金。 |
| 劳动仲裁 | 劳动争议的必经程序，一般应在知道权利被侵害之日起一年内申请，不收费。 |
| 定金 | 法律上的担保：给定金的一方违约不退，收定金的一方违约双倍返还，不超过合同总额 20%。 |
| 一般保证 | 债务人不能履行时保证人才承担责任，保证人可以先要求债权人找债务人执行。 |
| 连带责任保证 | 债务人到期不还，债权人可以直接要求保证人还钱。 |
| LPR | 贷款市场报价利率；民间借贷利率超过合同成立时一年期 LPR 四倍的部分不受法律保护。 |
| 诉讼时效 | 向法院请求保护民事权利的期限，一般为三年，催告、对方承认等会使其中断、重新计算。 |
| 支付令 | 债权债务清楚的金钱纠纷，可以向法院申请督促对方在十五日内清偿或提出异议。 |
| 小额诉讼 | 标的额较小、事实清楚的金钱给付纠纷适用的简便程序，一审终审。 |
| 财产保全 | 担心对方转移财产时，向法院申请查封、扣押、冻结对方财产。 |
| 人民调解 | 人民调解委员会对民间纠纷进行的调解，不收费，协议可以申请法院司法确认。 |
| 法律援助 | 国家为经济困难公民等提供的免费法律咨询、代理等服务，热线 12348。 |
| 人身安全保护令 | 遭受家暴或面临现实危险时，向法院申请禁止对方骚扰、接触、实施暴力的裁定。 |
| 人格权侵害禁令 | 有证据证明他人正在或即将侵害人格权时，向法院申请责令其停止的措施。 |
| 告诫书 | 家暴情节较轻、不予治安处罚时，公安机关对加害人出具的书面告诫。 |
| 正当防卫 | 为制止正在进行的不法侵害而采取的、未明显超过必要限度的防卫行为，不负刑事责任。 |
| 意定监护 | 成年人在清醒时以书面形式事先确定自己将来失能时的监护人。 |
| 好差评 | 政务服务评价制度，办事群众可以对服务进行评价，差评会被核实整改。 |
